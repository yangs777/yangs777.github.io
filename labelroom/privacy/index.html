라벨 작업

편집기에 넣은 이미지와 문구는 브라우저에서 처리하며 라벨룸 서버로 업로드하지 않습니다. ‘설정 저장’을 누르면 규격·문구·제외한 칸이 브라우저 저장소에 남습니다. 이미지는 저장하지 않습니다. 저장 데이터는 사이트 주소별로 구분되므로 다른 무료 주소로 이동하면 저장한 설정이 자동으로 옮겨지지 않습니다. 공용 기기에서는 브라우저의 사이트 데이터를 지워 주세요.

제안함에 저장하는 정보

제안 종류, 제목, 내용, 작성 이름(선택), 접수 시각, 공개 동의 여부를 서비스 개선과 문의 처리를 위해 저장합니다. 실제 이름·전화번호·주소 등 불필요한 개인정보는 쓰지 마세요. 보안 제보는 공개 동의와 관계없이 비공개로 처리합니다.

공개 여부와 조회 키

공개 동의가 있는 일반 제안은 검토 후 내용과 이름이 공개될 수 있습니다. 접수 때 발급하는 확인 키는 다른 사람에게 공유하지 마세요. 서버에는 확인 키의 해시만 저장하며, 이 기기에서 다시 조회하도록 브라우저에는 접수 번호와 확인 키가 저장됩니다.

스팸 방지와 운영

접수 횟수 제한을 위해 접속 IP와 날짜를 조합한 일 단위 해시를 저장합니다. 제안 데이터에 원본 IP를 저장하지 않습니다. 호스팅 제공자의 접속·오류 로그에는 서비스 제공에 필요한 네트워크 정보가 처리될 수 있습니다. 제안은 처리 이력 관리에 필요한 동안 보관하며, 작성자는 소개·문의 페이지에 안내된 절차로 삭제를 요청할 수 있습니다.

광고·외부 서비스

현재 실제 광고를 요청하는 스크립트와 방문자 행동 분석 도구는 설치하지 않았습니다. Google AdSense 소유 확인용 메타 정보와 ads.txt는 광고 게재 권한 확인을 위한 공개 정보이며, 이 정보만으로 광고 쿠키를 저장하지 않습니다. 광고를 활성화하기 전 사용하는 서비스와 수집 항목, 필요한 동의 방법을 먼저 안내합니다. 화면 제공에는 GitHub Pages와 Sites, 제안 저장에는 Sites 및 Cloudflare 인프라를 사용합니다. GitHub 무료 주소에서 제안함을 선택하면 기존 제안 서버 주소로 이동하며, 그 주소에서 접수·조회가 이루어집니다.
