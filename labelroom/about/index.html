ABOUT THIS LITTLE WORKSHOP

작은 인쇄에도,
편한 도구가 필요하니까.

라벨룸은 소량 라벨을 만드는 사람을 위한 무료 웹 작업실입니다. 복잡한 디자인 프로그램을 설치하지 않고, 필요한 수량만큼 칸을 채우고, 남은 용지의 빈칸을 골라 쓰고, 프린터마다 다른 인쇄 위치를 보정하도록 돕습니다. 로그인이나 결제 없이 바로 쓸 수 있습니다.

무엇을 하나요

  • A4·Letter 시트 라벨의 칸 배치 계산(사각형·원형, 0.1mm 단위)
  • 쓰다 남은 라벨지의 빈칸 지정(앞에서 건너뛰기, 칸별 제외)
  • 문구 최대 4줄과 이미지 넣기, 실제 크기 인쇄와 PDF 저장
  • 인쇄 위치 보정(가로·세로 ±10mm)과 설정 저장
  • 라벨 인쇄 길잡이: 규격 재기, 실제 크기 인쇄, 밀림 보정, 남은 라벨지, 식품 포장 표시사항

무엇을 하지 않나요

라벨에 넣은 이미지와 문구는 브라우저 안에서만 처리하고 서버로 보내지 않습니다. 실제 프린터·급지 방식·용지별 출력 결과는 보증하지 않으므로, 일반 종이로 먼저 시험 인쇄해야 합니다. 특정 라벨 제조사와 제휴하거나 공식 호환을 인증받은 서비스가 아닙니다. 결제나 유료 기능은 없습니다.

누가 만드나요

라벨룸은 yangs777.github.io를 운영하는 개인 운영자가 만들고 고칩니다. 같은 운영자가 3D 프린팅 소품 공방 예전의 무료 활동 자료실도 운영합니다. 화면은 GitHub Pages로, 제안함은 별도 서버로 제공합니다.

길잡이 글을 쓰는 원칙

길잡이 글은 운영자가 직접 씁니다. 규격 치수와 법령처럼 확인이 필요한 내용은 공식 문서를 확인한 것만 쓰고, 글 끝에 참고한 자료를 적습니다. 확인하지 못한 내용은 쓰지 않거나 "확인할 곳"을 안내합니다. 각 글에는 마지막으로 고친 날짜를 적고, 틀린 내용을 알려 주시면 확인한 뒤 고칩니다.

여러분과 함께 고칩니다

제안함에서 아이디어, 오류, 사용성 개선, 보안 제보를 받습니다. 유용성과 재현 가능성, 정확성, 개인정보 보호, 운영 비용을 살펴 반영 여부를 판단하고, 반영한 기능은 업데이트 기록에 버전과 함께 남깁니다. 작성자는 접수 번호와 확인 키로 자신의 제안을 조회할 수 있습니다. 공개에 동의하지 않은 제안과 보안 제보의 상세 내용은 공개하지 않습니다.

문의와 권리 요청

서비스 문의, 글 내용 정정, 콘텐츠 권리 문제는 이메일 yangs7777@gmail.com 또는 제안함의 ‘사용성 개선’으로 보내 주세요. 제안함에 남길 때는 공개 동의를 꺼 주세요. 기존 제안 삭제 요청에는 접수 번호와 확인 키를 함께 전달해 작성자 여부를 확인할 수 있게 해 주세요.
