ABOUT THIS LITTLE WORKSHOP

작은 인쇄에도,

라벨룸은 소량 라벨을 만드는 사람을 위한 웹 작업실입니다. 복잡한 디자인 프로그램을 설치하지 않고, 필요한 수량을 맞추고, 남은 용지를 골라 사용하도록 돕습니다.

여러분과 함께 고칩니다

제안함에서 아이디어, 오류, 사용성 개선, 보안 제보를 받습니다. 유용성과 재현 가능성, 정확성, 개인정보 보호, 운영 비용을 살펴 반영 여부를 판단하고 결과를 기록합니다. 작성자는 접수 번호와 확인 키로 자신의 제안을 조회할 수 있습니다.

매일의 검토 시각과 변경 내역은 업데이트 페이지에서 공개합니다. 기능 변경이 없는 날은 검토 기록으로 구분하고, 제안이 반영되면 해당 접수 번호를 버전에 연결합니다. 공개에 동의하지 않은 제안과 보안 제보의 상세 내용은 공개하지 않습니다.

문의와 권리 요청

서비스 문의, 콘텐츠 권리 문제, 제안 삭제 요청은 제안함의 ‘사용성 개선’으로 남기고 공개 동의를 꺼 주세요. 기존 제안 삭제 요청에는 접수 번호와 확인 키를 함께 전달해 작성자 여부를 확인할 수 있게 해 주세요.

현재 제공 범위

이 서비스는 라벨 배치와 인쇄 파일 준비를 돕습니다. 실제 프린터·급지 방식·용지별 출력은 직접 시험해야 합니다. 특정 라벨 제조사와 제휴하거나 공식 호환을 인증받은 서비스는 아닙니다. 현재 결제나 유료 생성 기능은 없습니다.
