라벨 인쇄 길잡이

소량 라벨을 직접 인쇄하면서 실제로 자주 막히는 부분을 하나씩 정리했습니다.
각 글은 라벨룸의 해당 설정과 연결되어 있습니다.

01 / 규격

라벨지 규격, 자 하나로 정확히 재는 법

가로·세로·여백·간격을 순서대로 재고, 용지 폭으로 검산합니다. 여백이 좌우로 다른 라벨지 처리법도 있습니다.

읽기 · 5분02 / 인쇄

라벨이 작게 찍힐 때: 실제 크기(100%)로 인쇄하기

배율 몇 %가 아래쪽 칸을 크게 끌어올리는 이유와, 자로 실제 배율을 계산하는 시험 인쇄법.

읽기 · 5분03 / 보정

인쇄가 밀릴 때 원인별 보정법

전체 밀림, 점점 어긋남, 기울어짐, 장마다 다름. 증상표로 원인을 먼저 찾습니다.

읽기 · 5분04 / 재사용

쓰다 남은 라벨지, 빈칸에만 인쇄하기

남은 칸 지정 두 가지와 급지 방향 확인. 그 전에 내 프린터가 일부 쓴 라벨지를 받는지부터 확인합니다.

읽기 · 4분05 / 표시사항

수제 식품 포장 라벨에 들어가야 하는 표시사항

법 조문에 실제로 적힌 표시 항목과 소비기한, 작은 라벨에 나눠 담는 방법, 확인할 기관.

읽기 · 6분06 / 라벨지

라벨지 고르는 법: 잉크젯용·레이저용·겸용과 광택·투명·방수 소재

라벨지는 크기보다 프린터 방식이 먼저입니다. 잉크젯용·레이저용·겸용 차이와 잘못 쓰면 생기는 번짐·녹음, 광택·투명·방수 소재 고르는 법.

읽기 · 6분07 / 이미지

라벨에 넣을 이미지, 몇 픽셀이면 될까: 해상도 계산법

mm를 픽셀로 바꾸는 계산식과 40×30mm·50×50mm·원형·A4 예시표. 작은 로고를 키우면 안 되는 이유와 투명 PNG 팁까지.

읽기 · 6분08 / 바코드

라벨에 바코드·QR 넣기: 안 읽히는 원인과 최소 크기

크기를 줄이거나 여백을 비우지 않으면 바코드는 안 읽힙니다. 최소 크기와 여백, 실패 원인 다섯 가지, 판매용 바코드 발급까지 정리합니다.

읽기 · 5분09 / 표시사항

수제 비누·화장품 라벨에 들어가야 하는 기재사항

화장품법 조문으로 본 비누·화장품 기재사항과 소용량·견본품 예외, 화장비누의 내용량 표시와 앞면·뒷면 라벨 나누기.

읽기 · 6분10 / 원형

원형 라벨, 그림과 글자를 가운데 맞추는 법

중심 간 거리로 간격을 재고, 지름 × 0.707로 글자와 로고가 들어갈 안전영역을 계산합니다. 원형에서 밀림이 더 잘 보이는 이유도 정리했습니다.

읽기 · 5분11 / 급지

라벨지가 걸리거나 비뚤게 들어갈 때: 급지 예방법과 안전하게 빼는 법

라벨지 걸림은 대개 넣는 방법에서 시작됩니다. 수동 급지, 용지 종류 설정, 보관 습기를 먼저 점검하고, 걸렸을 때 전원과 가열부를 어떻게 다룰지 제조사 안내로 확인합니다.

읽기 · 5분12 / 접착

라벨이 들뜨거나 떨어질 때: 붙이는 면·온도·압착 점검법

라벨이 들뜨는 원인은 대개 붙이는 면과 온도, 붙인 뒤의 처리입니다. 청소, 최소 부착 온도, 작은 병 겹쳐 붙이기, 냉장·냉동 제품 붙이는 순서를 증상표로 점검합니다.

읽기 · 6분13 / 표시사항

공방 수제 소품 온라인 판매, 라벨과 상품 정보에 확인할 것

3D 프린팅 소품·키링을 팔 때 판매자 정보, 어린이제품 KC 표시, 생활용품 대상 여부를 조문으로 확인합니다.
